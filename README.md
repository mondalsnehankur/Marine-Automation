# 🌊 Marine Automation: Machine Learning-Based Water Quality Prediction

## Overview

Marine Automation is a research-oriented project that integrates remote sensing, environmental data analysis, and machine learning to predict marine water quality parameters. The workflow combines satellite-derived environmental variables extracted from Google Earth Engine (GEE) with machine learning techniques to estimate nutrient concentrations and evaluate the Water Quality Index (WQI).

The project was developed as part of an academic research initiative focused on environmental monitoring and predictive analytics.

---

## Project Objectives

* Extract environmental parameters using Google Earth Engine.
* Build structured datasets from multiple monitoring stations.
* Analyze seasonal and spatial variations in marine water quality.
* Predict important nutrient concentrations using machine learning.
* Estimate Water Quality Index (WQI).
* Generate visual outputs and comparative analyses for different locations and seasons.

## Workflow

1. Collect environmental parameters using Google Earth Engine.
2. Export and organize datasets.
3. Perform data preprocessing and feature preparation.
4. Train machine learning models on historical observations.
5. Predict marine water quality parameters.
6. Calculate the Water Quality Index (WQI).
7. Compare results across seasons and monitoring stations.
8. Generate maps, graphs, and analytical outputs.
